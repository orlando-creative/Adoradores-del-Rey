DOCUMENTACION CORTA PARA IA: MIGRACION A APP MOVIL
=================================================================

RESUMEN EJECUTIVO
-----------------------------------------------------------------
Adoradores del Rey es un sistema web de gestión musical para iglesia con foco en:
- catálogo de canciones
- repertorios de servicio
- lectura de letras con acordes
- transposición de tonalidades
- visualización móvil para uso en reuniones
- administración de perfiles y roles

Actualmente está implementado como PWA web con HTML/CSS/JS y Supabase como backend. El sistema ya tiene una base clara de negocio y de datos, por lo que es muy apropiado para migrarlo a React Native/Expo, Flutter o Capacitor manteniendo la misma lógica.

OBJETIVO DE LA MIGRACION
-----------------------------------------------------------------
Convertir esta app web en una app móvil nativa o híbrida con:
- autenticación
- navegación por pantallas
- listado y detalle de canciones
- gestión de repertorios
- edición de contenido musical
- transposición de acordes
- exportación visual
- uso en dispositivos móviles con buena experiencia de lectura

-----------------------------------------------------------------

- public/index.html: pantalla principal de la app

RECOMENDACION DE STACK MOVIL
-----------------------------------------------------------------
Opción principal:
- React Native + Expo
- Supabase para auth + base de datos
- Zustand o Redux Toolkit para estado global
- React Navigation para pantallas
- Expo Router opcional
- react-native-svg o render nativo para acordes
- react-native-share / expo-sharing para compartir
- expo-print / react-native-view-shot para exportar imagen

Alternativa:
- Flutter + Supabase
- Riverpod/Provider
- go_router
- share_plus
- screenshot

SELECCION RECOMENDADA
-----------------------------------------------------------------
Para este proyecto, lo más práctico es:
- React Native + Expo + Supabase
Porque el sistema ya está basado en web, la migración es más rápida y el trabajo con formularios, listas, navegación y componentes es muy natural.

HALLAZGOS CLAVE PARA LA IA
-----------------------------------------------------------------
- app.js es el centro funcional del sistema, pero está muy acoplado.
- La lógica de negocio es clara y separable por dominios.
- Las entidades principales ya están definidas.
- Los datos están bien estructurados para backend centralizado.
- La parte más compleja es la lectura musical y la transposición, no la base de datos.
- El sistema está listo para migrarse manteniendo la misma fuente de verdad en Supabase.

RESUMEN FINAL
-----------------------------------------------------------------
La app ya define claramente sus entidades, reglas y flujos. Lo principal no es reconstruir la lógica desde cero, sino migrar la arquitectura, separar los dominios y adaptar la experiencia al móvil sin perder la funcionalidad musical del sistema. La mejor base para esta migración es React Native + Expo + Supabase, conservando el mismo modelo de datos y flujos de negocio que ya existen en este proyecto.
